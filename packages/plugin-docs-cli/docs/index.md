# Guides index

These guides ship with `@grafana/plugin-docs-cli`, so the copy in your `node_modules` always matches the
version of the CLI you have installed. Read the one that fits what you are doing:

| When you are...                     | Read                                                            |
| ----------------------------------- | --------------------------------------------------------------- |
| Writing or changing a page          | [Authoring guide](./authoring.md)                               |
| Unsure what markdown you can use    | [Supported markdown](./supported-markdown.md)                   |
| Moving docs from the docs website   | [Migrate from the docs website](./migrate-from-docs-website.md) |
| Fixing something `validate` reports | [Validation rules](./validation-rules.md)                       |
| Looking for background and setup    | [Plugin docs guides](./README.md)                               |

The authoring guide covers page shape, writing style and keeping docs in sync with your code. The last guide
covers why plugin docs exist, what the codemod scaffolds, how docs appear in the catalog and how they are
published.
